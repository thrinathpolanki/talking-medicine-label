- Added detailed documents: how it works, pin reference, firmware design, bill of materials, test plan, accessibility, enclosure, FAQ and glossary.
- Added more animations: animated wiring diagram, tag-to-audio sequence, NDEF bytes, DFPlayer frame, charging cycle, MT3608 adjustment, buttons, latch timeline, power budget, assembly stages, enclosure layout, troubleshooting flow.
- Added component name labels to every photo and a component gallery.
- Included 15 supplied component photographs (licences unverified).
- Found from photos: cell marked INR21700-45E (not 18650); speakers rated 0.5 W; resistor photo reads 1 ohm. Volume cap lowered accordingly.
- Merged the author's reference diagram: SPDT switch (COM, OUT, NC unused), GND* net, MT3608 OUT+/OUT- naming, HW-104 amplifier.
- Added animations to every Markdown file.
- Added three buttons (volume up and down, language), three LEDs, stereo output with two speakers.
- Initial repository: hardware design, firmware, tag format, documentation.
